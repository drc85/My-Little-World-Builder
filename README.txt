MY LITTLE WORLD BUILDER

Double-click START-BUILDER.bat to start the server minimized and open the Builder in your default browser.
The server stays in the taskbar. Close its window to stop it.
Starting again reuses the running server.

Open Asset Manager from the welcome screen, or use START-ASSET-MANAGER.bat.
Manager files and catalog are directly inside assets/. Models stay in assets/BROWSER/.
Main categories are the top-level BROWSER folders. Subcategories are their nested folders.
Python 3 is required.
